BELMOR REPRESENTACIONES - WEB VERSION 3.0

Archivo principal:
index.html

Carpetas:
assets: imágenes, logo, video e imagen para metadata
css: estilos editables
js: funciones del formulario y video

Metadata agregada:
- Open Graph para WhatsApp, Facebook y redes sociales.
- Twitter Card.
- Imagen principal para compartir: assets/meta-logo.png
- Favicon usando el logo.

Importante al publicar:
En index.html, cambia esta línea por la URL final real del sitio:
<meta property="og:url" content="https://tudominio.com/">

Para que WhatsApp y Facebook muestren correctamente la imagen, la web debe estar publicada en internet y la imagen debe estar accesible desde el dominio.
