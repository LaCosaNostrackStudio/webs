BELMOR REPRESENTACIONES - WEB EDITABLE

Archivos principales:
- index.html: estructura de la página.
- css/styles.css: colores, tamaños, estilos y responsive.
- js/main.js: formulario conectado a WhatsApp.
- assets/: imágenes, logo y video.

Cómo editar en Dreamweaver:
1. Abre la carpeta belmor_web como sitio.
2. Edita index.html para cambiar textos.
3. Edita css/styles.css para cambiar colores y estilos.
4. Para cambiar imágenes, reemplaza archivos dentro de assets usando el mismo nombre o actualiza la ruta en index.html.
